# ONBEAT 온비트

이어폰 속 노래가 눈앞의 무대가 되는 AR 음악 시각화 서비스 콘셉트입니다.
지금 듣는 음악을 실시간으로 분석해서 AR로 눈앞에 빛, 파동, 입자로 그려 줍니다. 클럽에 가지 않아도 길거리에서 비트에 맞춰 춤출 수 있게 하는 것이 목표예요.

**웹사이트 보기:** https://2023098-design.github.io/onbeat-ar/

## 데모에서 해 볼 수 있는 것

- **장르 고르기:** 신나는 팝, 힙합, 로파이, EDM 비트를 브라우저에서 직접 합성해서 재생하고, 그 소리를 실시간으로 분석해 반응합니다.
- **내 음악 올리기:** 가지고 있는 음악 파일을 올리면 그 곡을 분석해서 반응합니다. 파일은 브라우저 안에서만 재생되고 업로드되지 않아요.
- **효과 끄기 / AR:** 같은 거리를 효과 없이 볼 때와 AR로 볼 때를 비교할 수 있어요.
- **친구와 함께:** 친구를 초대하면 같은 박자 시계로 동기화돼서, 킥이 칠 때 모두의 발밑 파동이 동시에 퍼지고 나에게서 친구에게로 박자 신호가 흘러가요. ‘다 같이 점프’를 누르면 모두의 화면에 큰 파동이 터집니다. (데모 속 친구는 가상 인물이에요.)

## 소리 → 빛 변환 규칙

| 소리 요소 | 읽어 내는 값 | 눈에 보이는 것 |
| --- | --- | --- |
| 킥 드럼 (20–150 Hz) | 치는 순간 | 발밑에서 퍼지는 파동 링 |
| 스네어 · 박수 (1.5–4 kHz) | 치는 순간 | 시야 가장자리가 은은하게 빛남 |
| 하이햇 · 고음 (5–12 kHz) | 에너지 | 떠오르는 빛 입자 |
| 멜로디 · 보컬 (300 Hz–2 kHz) | 에너지 | 공중을 흐르는 빛 리본 |
| 전체 주파수 (12개 대역) | 대역별 크기 | 건물 창문 이퀄라이저 |
| 템포 (BPM) | 박자 속도 | 모든 효과의 박자 |
| 분위기 | 밝기와 색온도 | 팔레트의 톤 |

## 파일 구성

- `index.html` 페이지 구조와 스타일
- `app.js` 음악 합성, 실시간 주파수 분석, 캔버스 시각화, 친구와 함께 모드

별도 설치나 빌드 없이 `index.html`을 브라우저로 열면 바로 동작합니다. 화면은 AR로 보이는 모습을 흉내 낸 시뮬레이션이에요.
